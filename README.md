# Telegram Bot for MTUCI Applicants

Telegram-бот, разработанный для автоматизации информационного взаимодействия с абитуриентами Московского технического университета связи и информатики (МТУСИ) в рамках приемной кампании. Бот предоставляет доступ к персональным данным, статусу заявлений и другой важной информации, интегрируясь с внутренними системами вуза.

## Основные функции

-   **Регистрация и аутентификация:** Привязка аккаунта Telegram к учетной записи абитуриента через подтверждение номера телефона и e-mail.
-   **Персонализированная информация:** Предоставление данных о поданных заявлениях, результатах внутренних вступительных испытаний (ВИ) и ЕГЭ, индивидуальных достижениях.
-   **Редактирование данных:** Возможность изменения контактных данных (e-mail, ИНН) с обязательной валидацией.
-   **Обратная связь:** Функция отправки сообщений в приемную комиссию напрямую через бота.
-   **Push-уведомления:** Получение абитуриентами уведомлений о ключевых событиях приемной кампании.

## Технологический стек

-   **Бэкенд:** Python 3.9+
-   **Фреймворк для бота:** Aiogram
-   **База данных:** PostgreSQL (для хранения данных пользователей, логов и кэша)
-   **Контейнеризация:** Docker, Docker-compose
-   **Взаимодействие с API МТУСИ:** Requests, Aiohttp
-   **Безопасность:** Шифрование данных, валидация ввода

## Установка и запуск

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/Losyara9/Ab_MTUCI_Bot.git
    cd Ab_MTUCI_Bot
    ```

2.  **Настройте переменные окружения:**
    Создайте файл `.env` на основе примера (`.env.example`) и заполните данными, предоставленными администрацией МТУСИ:
    ```env
    BOT_TOKEN=your_telegram_bot_token_from_BotFather
    DB_HOST=db
    DB_PORT=5432
    DB_NAME=mtuci_bot
    DB_USER=postgres
    DB_PASSWORD=your_secure_password_here
    API_MTUCI_BASE_URL=https://... # Базовый URL API МТУСИ
    API_MTUCI_KEY=your_api_key_here # Ключ для доступа к API МТУСИ
    ```
    *Для работы необходимы доступы к API внутренних систем университета.*

3.  **Запустите сервисы с помощью Docker-compose:**
    ```bash
    docker-compose up -d
    ```
    Бот будет развернут и готов к работе. Для полноценной интеграции необходимо настроить подключение к API МТУСИ.

## Интеграция

Проект реализован в соответствии с Техническим заданием на интеграцию с системами МТУСИ:
-   **ЭИОС (Электронная информационная образовательная система):** Синхронизация данных абитуриентов.
-   **"1С:Университет ПРОФ":** Обмен данными о заявлениях и учетных записях.
-   **Внутренняя ИС вуза:** Получение актуальной информации о ходе приемной кампании для рассылки уведомлений.
